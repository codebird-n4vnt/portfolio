# Navneet Sahu — portfolio

My personal site: who I am, what I've built, and how to reach me.

Built with Next.js 16 (App Router), React 19 and Tailwind CSS v4. Design tokens live in
`app/globals.css`; each section of the page is a component in `components/`.

## Run it

```bash
npm install
npm run dev      # http://localhost:3000
npm run build    # production build
```

## Editing content

- Projects: `components/Projects.tsx` (the `featured`, `projects` and `moreProjects` lists)
- Skills: `components/Skills.tsx`
- Hackathons and certifications: `components/Achievements.tsx`
- Photo: `public/profile.jpg`
